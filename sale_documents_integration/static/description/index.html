This module is for connecting Attachments of the sale order to the Documents.
New "Documents" button on the "Sale Order" form view.

The total count of the Attachments of a sale order will be visible on the Documents button.

All the Attachments of a sale order will be set in the Sale Order folder of the Documents.

By default, a Sale Order folder will be created to save Attachments of a sale order. Although we can also create a custom folder and configure it on Settings > Documents > Files Centralization.
