Website Denomination.

This module is used to genereate gift voucher for discount to be applied on webshop order for particular customer.

Features

Create Gift Voucher

User can configure specific gift voucher and Amount, also write comment.

Apply Discount & Validation By Unique Voucher code

Validation apply on invalid voucher code or already used voucher.
Demo Request Video Tutorial

How to create Gift Voucher

You can create Gift Voucher goto Sales > Gift Voucher.

Website Voucher Configuration

On website shopping cart view you can activate the voucher by clicking on customize tab and apply voucher code.

Apply Voucher Code and Add Message Button View

You have to enter created voucher code here and voucher amount will be deducted from total amount also you can send message.

Website Message

In webshop, when you click on add message button one wizard will open, You have to enter any message and click on send message button to send the message.

Sale order View

Here you can see applied voucher code will be shown in the order with their amount.

Sale Order Message

After click on send message button in webshop, entered message is display on sale order.

Used Gift Voucher

If gift voucher is used once then in gift voucher "Used" is automatically set as true.

Invalid Voucher Error

We can not use any gift voucher if there gift voucher is not created. It will be raise Error.

Already Used Voucher

Once a gift voucher is used then we can not use it again. It will be raise Error.
